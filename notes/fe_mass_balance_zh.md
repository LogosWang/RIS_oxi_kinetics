# 晶界氧化物的 Fe 排出：质量守恒推理与体积收支

记录日期：2026-11-03。文中行号对应当日未提交的 `main.tex`，之后可能错位。

## 结论

1. Fe 必须从晶界氧化物中排出。这由质量守恒和 EDX 数据直接得出，不依赖模型参数。
2. 模型只取 Aziz 的界面分配，分配后的原子还能移动。这是与 Aziz/Yu 的差别，不是模型内部的矛盾。
3. 氧化物体积小于消耗的金属体积，同样是数据的推论，不是模型缺陷。
4. 仍需交代三件事：正文点明与 Aziz/Yu 的差别，说明体积亏空的去向，说明外排通量的阻力。其中体积亏空可能影响孔隙率的结果。

## 1. 质量守恒推理

这个论证由作者提出，前提如下：

- EDX 显示氧化物中 Cr 远多于 Fe。
- 界面金属一侧没有明显的 Cr 贫化或 Fe 富集，所以氧化没有从周围金属额外抽取 Cr。
- 因此氧化物中的 Cr 只来自被前沿扫过的金属，多出来的 Fe 必须离开。

另外，320 °C 下体扩散很慢，贫化区一旦形成很难被填平，所以“没有贫化”可以看作整段历史的记录。这一点是我的判断，没有做定量计算。

### 公式

记合金 Cr 分数为 c，氧化物金属基 Cr 分数为 x，并以每扫过 1 个金属原子为基准：

- 留在氧化物中的比例：r = c / x
- 排出的比例：f = 1 − r
- 氧化物中的 Fe：r(1 − x)
- 氧化物与消耗金属的体积比：V = N [ (c/2) Ω(Cr2O3) + (r(1 − x)/3) Ω(Fe3O4) ]
- 消耗的氧原子：O = 1.5c + (4/3) r(1 − x)

### 取值

- c = 0.19，x 取 Deng 2017 的值。
- N = 87 nm⁻³，ρ(Cr2O3) = 5.22 g/cm³，ρ(Fe3O4) = 5.17 g/cm³，都来自草稿表 3。
- 由此得 Ω(Cr2O3) = 0.0484 nm³，Ω(Fe3O4) = 0.0744 nm³。
- 只算 Cr2O3 和 Fe3O4，忽略 Ni 和 Si。

### 结果

| | 0 dpa | 0.5 dpa | 3 dpa |
|---|---|---|---|
| 氧化物 Cr x（at%） | 74.9 | 69.5 | 58.3 |
| 留下比例 r | 25% | 27% | 33% |
| 排出比例 f | 75% | 73% | 67% |
| 体积比 V | 0.54 | 0.58 | 0.69 |
| 体积亏空 1 − V | 46% | 42% | 31% |
| 排出金属与进入氧的通量比 f / O | 2.0 | 1.8 | 1.45 |

V = 1 对应 x ≈ 41%。Cr 超过这个值，氧化物就填不满消耗掉的金属体积。Deng 的三个值都高于它。

### 敏感性和局限

- c 取 18–20 at% 时，V 分别为 0.51–0.57、0.55–0.61、0.66–0.73，结论不变。
- 草稿 `fig:oxide-chem` 的图注把模型的最小 Cr 与 Deng 的 EDX 值比较（`main.tex:1161–1163`）。如果这些 EDX 值是谷底值，截面平均的 Cr 会更高，高剂量下的亏空会大于表中数字。这一点要回原文确认。
- 表中用的是晶态密度，而 Deng 2017 描述氧化物的 FFT 接近非晶。实际密度更低时，V 会偏大，亏空偏小。

### 文献依据

- Deng 2017、2020：Fe 经氧化物向外扩散，供给外层颗粒。
- Deng 2017：没有 Ni 富集说明氧化快到来不及选择性移除 Cr 和 Fe，方向与此一致。
- Robertson 1991：内层原位生长，Fe 向外扩散形成外层。
- Young 的 available space 模型：Fe 外排，金属消耗注入空位并形成孔洞。

以上来自知识库笔记，没有逐一回原文核对。

## 2. 与 Aziz/Yu 的关系

| | Aziz / Yu | 本模型 |
|---|---|---|
| 界面分配 | k(v) = (v/v_D + k_e)/(v/v_D + 1) | 同一形式，k_e = 0（`main.tex:618–628`） |
| 被捕获的原子 | 留在新相中，不再移动 | 可沿氧化物晶界继续排出（`main.tex:609–611`） |
| 前沿很快时 | 氧化物成分趋于合金成分 | 氧化物成分由实际氧化的量决定 |

因此 λ 只决定原子最后在界面哪一侧，Yu 的“快前沿继承合金成分”极限不适用，因为它默认被捕获的原子留在氧化物中。按知识库笔记，Yu 2018 的 v_a = −c_o v_I + j_oΩ 本身含跨界面的阳离子通量，所以这个做法不算陌生。Yu 的补充材料 S5 我没有读。

还要注意两点：

- 草稿目前写的是“solute trapping 的氧化类比”和“capture regime”（`main.tex:612–616`、`635`），没有点明这个差别。Yu 明确提出了快前沿极限，审稿人很可能拿它来问。
- Fe、Cr、Si 的 v^r 都取 capture 极限，只有 Ni 是校准值（`main.tex:966–969`）。所以 Aziz 的公式实际只对 Ni 起作用。Fe 不被排回金属这个假设，主要依据应该是第 1 节的质量守恒。

## 3. 体积亏空的去向

接受亏空这个事实后，还要说明这部分空间到哪里去了。可能的去向有三种，也可能同时存在：

| 去向 | 对模型的影响 | 现状 |
|---|---|---|
| 晶粒靠拢，氧化物致密 | 不影响现有结果，但要明说。沿深度不均匀的靠拢会带来金属变形 | 现有方程隐含这一种：金属整体平移（`main.tex:652–655`），宽度只算氧化物体积（`main.tex:586–593`） |
| 留成孔隙 | 亏空远大于 SiO2 孔隙，而且趋势相反 | Archie 项目前只计 SiO2 孔隙 |
| 氧化物密度低或含水 | 亏空被部分抵消，取决于实际密度 | 没有数据；Robertson 1991 提到钝化膜因水合，膜与金属的体积比达到 3 |

第二种情况的对比：

| | 0 dpa | 0.5 dpa | 3 dpa |
|---|---|---|---|
| 体积亏空 | 46% | 42% | 31% |
| 模型 SiO2 孔隙（`main.tex:1185–1188`） | 1.6 vol% | 口部 1.8，前沿约 10 vol% | 口部 2.5，前沿约 22 vol% |

如果这些孔连通，Archie 项的基线和“Si 孔隙驱动剂量依赖”的解释都要重新检查。Kuang 2022 在质子辐照 316L 的氧化物中心观察到多孔界面（草稿 `main.tex:1196–1198` 引用），说明孔确实存在，但没有说明数量是否达到这个量级。

### 可用现有数据做的检验

- **Cr 谷宽度（优先）：** 金属侧的 RIS 剖面给出原始宽度。氧化物完全致密时，氧化物中的谷宽约为它的 V 倍（0.54–0.69）；孔隙留在原位时约为 1 倍。限制是 RIS 区只有几 nm，而 EDX 探针约 1 nm。
- **氧化物总宽度：** 模型在半深度处给出 32、16、10 nm（`main.tex:1194–1195`），可以和 Deng 的测量比较。但模型宽度也依赖校准的动力学，所以这只是辅助判据。

这两项对比都还没有做。

## 4. 外排通量的阻力

Fe 排出是事实，但模型假设它没有阻力。排出金属的通量是进入氧通量的 1.5–2 倍，走的是同一段氧化物。而在 Robertson 的图像里，控速的是 Fe 外扩散。

粗估所需的 Fe 有效扩散系数。假设前沿速度沿深度均匀，氧化物宽度为 2V·v·t，氧化物中的 Fe 全部可动，浓度沿深度线性下降：

D ≈ [ f / (r(1 − x)) ] · H² / t

| t = 500 h | 0 dpa | 0.5 dpa | 3 dpa |
|---|---|---|---|
| 系数 f / (r(1 − x)) | 11.7 | 8.7 | 5.0 |
| H 取 Deng 2017 的约 40、60、120 nm 时的 D（nm²/s） | 0.010 | 0.017 | 0.040 |
| H 统一取 100 nm 时的 D（nm²/s） | 0.065 | 0.048 | 0.028 |

这些值比草稿的 D_por（1 nm²/s）小约 15–100 倍，所以外排未必是瓶颈。但 D_por 是氧在孔隙中的扩散系数，不能代表 Fe。我没有查 320 °C 下可比的 Fe 扩散数据，所以还不能下结论。这是量级估算，只用来判断是否需要进一步处理。

至少要把“外排无阻力”写进局限（`main.tex:1567–1573`），最好附上这个估算。
