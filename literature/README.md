修订后的英文初稿引用五篇论文（Deng 2017、Deng 2021、Kuang 2022、Du 2026、Kadambi 2025）；Wang 2022/2023 和 Lach 2025 保留为讨论背景。八篇论文均有本地 PDF。阅读记录区分直接观察、作者提出的解释和本文的建模近似。这里的“核读”指阅读原文的相关方法、结果、讨论和结论并回查关键图；不是仅凭摘要，也不表示逐行审校了整篇文章及所有附录。

研究对象为 **304SS**。Kuang 和两篇 Wang 的材料为 316L，Lach 为服役 316；相关机制背景不等同于本文材料的验证数据。模型中 Cr 含量与 Si 溶解产生的自由体积共同影响 D_eff；氧化物保护性通过氧传输阻力体现，不与传输并列为独立机制。

作者澄清记录：时间依赖的氧化前沿图来自另一篇论文，其题名/DOI 待补充，未将它默认为 Deng 2017 或 Wang 2023。本文采用的 SiO₂ 全溶解处理是基于 Du 的 Cr/Si 解耦研究建立的简化假设；Du 提供氧化物溶解导致孔隙和传输增强的机制依据，完全溶解及其体积处理由本模型规定。
